# 🚀 Leonardo Caraguay - Portfolio

Portafolio profesional bilingüe (Español/Inglés) construido con **Astro** y **Tailwind CSS**. Ultra rápido, optimizado para SEO y 100% responsive.

![Astro](https://img.shields.io/badge/Astro-7.1.3-FF5D01?style=flat-square&logo=astro&logoColor=white)
![Tailwind CSS](https://img.shields.io/badge/Tailwind-4.3.3-38B2AC?style=flat-square&logo=tailwind-css&logoColor=white)
![TypeScript](https://img.shields.io/badge/TypeScript-5.x-3178C6?style=flat-square&logo=typescript&logoColor=white)

## ✨ Características

- ⚡ **Ultra Rápido**: Tiempo de carga < 1 segundo
- 🌍 **Bilingüe**: Español/Inglés con cambio instantáneo
- 📱 **100% Responsive**: Mobile-first design
- 🎨 **Dark/Light Mode**: Con persistencia en localStorage
- 🔍 **SEO Optimizado**: Meta tags completos, Open Graph, Twitter Cards
- ♿ **Accesible**: Atributos ARIA, navegación por teclado
- 🎯 **0 KB JS por defecto**: Astro Islands Architecture

## 🚀 Inicio Rápido

```bash
# Instalar dependencias
npm install

# Desarrollo con hot-reload
npm run dev

# Build para producción
npm run build

# Preview del build
npm run preview
```

El sitio estará disponible en **http://localhost:4321**
